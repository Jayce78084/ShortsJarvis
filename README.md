# ShortsJarvis

ShortsJarvis is a focused planning workspace for creators making TikTok videos,
Instagram Reels, and YouTube Shorts.

The MVP will use transparent, rule-driven templates rather than external AI
services. It will not require an API key, account, or paid service.

## Requirements

- Node.js `22.23.3` (see `.nvmrc`)
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

## Verify the project

```bash
npm test
npm run build
```

## Current scope

Phase 1 establishes the Vite application foundation and a minimal browser
entry point. The dashboard, planner, rule-driven generation, Hook Lab,
readiness scoring, local saved plans, and export tools will be added in later
verified steps.
